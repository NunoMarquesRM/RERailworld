# RERailworld

RERailworld is a comprehensive railway expansion mod for Factorio that introduces advanced train technologies, specialized wagons, and powerful locomotives. This mod enhances the railway system with new tiers of trains, cargo wagons, fluid wagons, and specialized machinery trains. Designed to complement the RExtended mod, RERailworld provides a complete overhaul of the railway system with multiple progression paths and specialized transport solutions.

## Features

- **Advanced Train Technologies**: Multiple tiers of locomotives with increasing capabilities
- **Specialized Transport Solutions**: Purpose-built wagons for different cargo types
- **Sonic Trains**: Ultra-high-speed locomotives capable of extreme velocities
- **Electric Trains**: Efficient, clean-powered alternatives to traditional trains
- **Workshop Trains**: Mobile manufacturing facilities for on-the-go production
- **Advanced Fuel Systems**: Multiple tiers of specialized fuels with increasing performance
- **Integrated Progression**: Seamless integration with RExtended mod technologies
- **Balanced Gameplay**: Carefully balanced to maintain game progression while adding new options

Workshop trains are a unique addition to the RERailworld mod, allowing for mobile manufacturing facilities. These trains can produce items while moving along your railway network.

### Workshop Locomotive R1

## Progression Paths

RERailworld offers multiple progression paths for your railway system:

1. **Traditional Path**: Start with standard trains and gradually upgrade to more advanced models
2. **Sonic Path**: Focus on developing sonic trains for maximum speed
3. **Electric Path**: Develop electric trains for clean, efficient transport
4. **Workshop Path**: Utilize workshop trains for mobile manufacturing

Each path has its own advantages and can be pursued independently or in combination with others.

## Integration with RExtended

RERailworld is designed to work seamlessly with the RExtended mod:

- Compatible crafting categories (red-workshop-locomotive, red-workshop-wagon, etc.)
- Uses RExtended components (Reinforced Plates, Electric Components, etc.)
- Balanced progression that aligns with RExtended technologies
- Complementary features that enhance both mods

## Installation

1. Download the mod
2. Place it in your Factorio mods folder
3. Enable the mod in Factorio
4. Start a new game or load an existing save

## Compatibility

- Compatible with Factorio 2.0
- Designed to work with RExtended mod
- May be compatible with other mods that don't modify train mechanics
- For best experience, use alongside RExtended mod
